# How do repeating tasks work?
Decided in #10

**Applies when:** creating, ticking or showing a task that repeats.

**Answer:** The way Todoist does it: a repeating task is one task with a repeat rule. Ticking it stamps that day's sticker as done, so it stays on the page, and moves the task to its next date.

**Why:** Repeating tasks are table stakes for replacing Todoist in a household, where chores repeat. One task that moves forward keeps lists short, while the stamped sticker keeps the visible record of what got done.

**Rejected:** Creating a separate task for every occurrence, which fills lists with copies.
