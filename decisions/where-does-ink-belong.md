# Where does ink belong?
Decided in #10

**Applies when:** deciding what a stroke is attached to, how it moves, who can see it, or what happens to it when something else on the page changes.

**Answer:** Ink always belongs to a page, never to a sticker or a text block. A stroke's position is measured either from the page or, when it was drawn on top of a typed text block, from that block, so it moves when the block moves. The block is only a reference point: deleting it leaves the ink on the page where it was. Notes that should travel with an item go on that item's own body page.

Until ink option C (milestone 9), ink is positioned from the page only. What happens to a block's ink when the block flows onto the next page is still open (#42).

**Why:** One owner keeps visibility and sync simple: ink follows its page's rules. Attaching ink to stickers would add scope, and ink that attaches to objects in ways people can't predict is a known frustration in other canvas apps.

**Rejected:** Ink owned by stickers, which adds scope and makes attachment unpredictable. Ink owned by text blocks: a block only gives a position.
