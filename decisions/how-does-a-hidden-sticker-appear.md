# How does a hidden sticker appear?
Decided in #10

**Applies when:** showing a page to someone who can't see some of its stickers.

**Answer:** In the same spot and with the same shape, with its contents hidden (for example greyed out or scribbled over), so others know something is there without seeing what. It is never labelled "private".

**Why:** The layout stays identical for everyone, so shared scribbles stay next to the right sticker. Hiding it playfully fits Foyer better than a formal label.

**Rejected:** Leaving a gap, which looks unexplained. Arranging each person's stickers separately, which misplaces shared notes. A "private" label, which feels too serious.
